# 模型说明（M1–M10）

> 对应需求文档第 7 章。实现见 `engine/models/pooled.py`（合并模型）与 `engine/models/single.py`（单股模型），
> 公式唯一实现在 `engine/formulas.py`，前端「公式说明」弹窗逐条解释参数来源与入参统计口径。

## 总体架构

```
stock_daily (前复权 500日窗口)
   → 清洗 / 股票池 / 特征（50+ 特征 + 12 个离散信号）
   ├─ 方向 M1 条件概率·贝叶斯    M2 逻辑回归    M3 马尔可夫链
   ├─ 波动 M4 GARCH(1,1)-t（失败回退 EWMA）
   ├─ 幅度 M5 条件期望    M6 分位数回归    M7 FHS 蒙特卡洛
   └─ 风险 M8 VaR/CVaR    M9 EVT（POT/GPD）
         ↓
   M10 Stacking + 概率校准 + 联合一致性
         ↓
   prob_prediction 落库 → settle 结算 → evaluate 评估 → backtest 回测 → 前端
```

**作用范围**：M3/M4/M7/M8 是单股模型（只用该股窗口内数据，参数很少）；M1/M2/M5/M6/M9 用全市场「股票×日期」合并样本训练，特征做横截面标准化。

**计算顺序**：M4 波动 → M1/M2/M3 → M10 得到 `p_up` → M5 期望 → M6/M7 分布 → M8/M9 风险 → 评级。

---

## M1 条件概率与贝叶斯（合并）

- 公式：`P(Y=1|S) = (k + m·p0)/(n + m)`，即 Beta(m·p0, m(1−p0)) 先验的后验均值；多信号用 `logit(p)=logit(p0)+Σ(logit(p_i)−logit(p0))` 合并。
- 输入：12 个布尔信号（MACD 金叉/死叉、RSI14<30/>70、量比>2、均线多头、连跌/连涨≥3、近 20 日有涨停、日收益 z>±2、market_ret_1>0）；单信号与 ≤3 个信号的组合分别统计。
- 统计口径：样本按 `w=0.5^(age/half_life)` 衰减后再累计加权 n、k（half_life=60 交易日）；组合有效样本 < min_n(30) 回退父级；Wilson 区间给 ci_low/ci_high。
- 输出：`prob_signal_stat`、`components_json.p_m1`。
- 注意：指标相关，独立性假设不成立，只作为 M10 输入，不直接发布。

## M2 逻辑回归（合并）

- 公式：`P(Y=1|X)=σ(β₀+ΣβⱼXⱼ)`，L2 正则。
- 输入：40+ 标准化特征（含横截面排名）；训练期 winsorize → 中位数填充 → z 标准化。
- 统计口径：按交易日等权 `w=1/当日样本数`；C 用带 purge 的时间序列 CV 选择；训练样本上限 150000，按日均匀抽样。
- 输出：`components_json.p_m2`、`contributions`（βⱼ·Xⱼ 前 10 项）、`prob_model_registry.params_json.coef`。

## M3 马尔可夫链（单股）

- 公式：`P_ij=(n_ij+1)/(Σn_ij+3)`，`π_h = π_1·P^(h−1)`；状态阈值 `θ_t = κ·σ_t`（κ=0.5）。
- 输入：该股全部有效日收益与 M4 条件波动；拉普拉斯平滑；卡方独立性检验 p>0.10 时每行与无条件状态分布各占 50% 收缩。
- 输出：`p_markov_h`、转移矩阵、`P_UU/P_DD`、期望连涨 `1/(1−P_UU)`。
- 注意：`π_h(U)` 是「第 h 天当天上涨」的概率，**不是** h 日累计收益>0 的概率。

## M4 GARCH(1,1)-t（单股）

- 公式：`σ²_t = ω + α·ε²_{t−1} + β·σ²_{t−1}`，`z ~ 标准化 t(ν)`；`σ_h² = Σ_{k=1..h} [σ̄² + (α+β)^(k−1)(σ²_{t+1}−σ̄²)]`。
- 输入：该股最近 500 个有效收益（×100 拟合再还原）；MLE 约束 ω>0、α+β<0.999、2.5<ν≤30。
- 回退：不收敛/触边/样本<250 → EWMA `σ²_t=0.94σ²_{t−1}+0.06r²_{t−1}`，记 `vol_model='EWMA'` 并降级。
- 诊断：标准化残差平方 Ljung-Box、Jarque-Bera p 值。
- 输出：`prob_stock_model_state`、`vol_1d_next` / `vol_h` / `vol_pctile_self` / `vol_pctile_mkt`。

## M5 条件期望（合并）

- 公式：`E[R_h] = p_up·k_up·σ_h + (1−p_up)·k_dn·σ_h`，`k_up/k_dn` 是 `R_h/σ_h` 在上涨/下跌样本上的均值。
- 统计口径：全市场合并样本、按日等权、先 winsorize 再估计。
- 输出：`components_json.exp_ret_cond`（交叉检验），最终 `exp_ret` 取一致性分布均值；符号相反记 `EXP_SIGN_MISMATCH`。

## M6 分位数回归（合并）

- 公式：pinball `ρ_τ(u)=u(τ−1[u<0])`，τ ∈ {0.05,0.25,0.5,0.75,0.95}，目标为标准化收益 `R_h/σ_h`。
- 实现：向量化 mini-batch SGD（≤20 个精简特征），固定种子；分位交叉时排序修正。
- 输出：`components_json.q_quantreg`、参与方法择优。

## M7 蒙特卡洛 FHS（单股）

- 公式：`r_{t+k} = μ_d + σ_{t+k}·z*_k`，`z*_k` 从 M4 标准化残差有放回抽样；每日简单收益按涨跌停 `clip([−L,+L])`。
- 参数：`n_paths=10000`，种子 `hash(code, asof_date, seed_base)`；基线 GBM `S_{t+Δ}=S_t·exp[(μ−σ²/2)Δ+σ√Δ·Z]` 仅作对照。
- 输出：`q05–q95`、`prob_drop_5/10`、`prob_rise_5/10`、分布均值、VaR/CVaR。
- OOS 快速模式用 location-scale t 解析分布代替，LIVE 用完整 FHS。

## M8 VaR / CVaR（单股）

- 公式：`VaR_α = −Q_{1−α}(R_h)`，`CVaR_α = −E[R_h | R_h ≤ Q_{1−α}]`（正数损失率）。
- 输出：`var95/var99/cvar95`、`breach_var95`；历史描述量 MDD、年化 Sharpe、年化波动。

## M9 EVT / POT（合并）

- 公式：`L=−z` 超限量 `y=L−u ~ GPD(ξ,β)`；`VaR_p = u+(β/ξ)[((n/N_u)(1−p))^(−ξ)−1]`，`ES_p=(VaR_p+β−ξu)/(1−ξ)`。
- 统计口径：全市场残差按波动率三分组，阈值取各组 90% 分位；超限样本 <50 回退 Student-t。
- 输出：`prob_model_registry(M9_evt_*)`、`prob_method_choice(VaR_evt_*)`。

## M10 融合、校准与联合一致性

1. **Stacking**：非负系数逻辑回归，输入 `logit(p_m1/p_m2/p_markov/p_base)` 与 `vol_pctile_self`；只用样本外 L1 预测训练（滚动 L2，带时间过滤）。
2. **校准**：样本外 ≥5000 用 isotonic，否则 Platt；最近样本外块评估 ECE。
3. **截断**：`p_up ∈ [0.05, 0.95]`。
4. **联合一致性**：二分求漂移 μ_d 使模拟 `P(R_h>0)=p_up`（所有候选漂移共用同一批随机数）；涨跌停截断导致二分不收敛时对同一批路径做位置平移等价求根，保证 ≤0.002 误差。
5. **禁止**：未校准的简单平均、相关指标概率直接相乘。

## 训练与评估

- **Walk-forward**：预热 1–60 日，L1 初始训练 61–240 日，241–500−h 每 20 日一个测试块；训练剔除与测试块标签重叠的最后 h 日（purge）；L2 用此前样本外块滚动训练。
- **指标**：Brier / LogLoss / AUC / ECE / BSS / MAE / RankIC / IC_IR / 分位覆盖率 / pinball / QLIKE / VaR 突破率 / Kupiec p 值；按全市场、分月、波动分组、周期分别输出，附基准 B0/B1/B2 差异与 block bootstrap 置信区间。
- **可靠性评级**：周期层 BSS>0 且 CI 下界>0 → A；BSS>0 → B；否则 C。个股每命中一项（EWMA 回退、有效样本<300、VaR 突破超 Kupiec 区间、EXP_SIGN_MISMATCH、近 20 日停牌/涨停≥3）降一档，最低 D。
- **回测**：t+1 开盘买入、t+1+h 收盘卖出、一字涨停买不到、跌停顺延；佣金/印花税/滑点可配置；等权组合每笔占 1/h 资金；净值、年化、Sharpe、MDD、胜率二项检验、相对等权基准超额。

## 验收要点

- 不以胜率/AUC 高为准，而看校准是否良好、是否不劣于基准、分位与 VaR 覆盖率是否合格、可靠性是否如实标注。
- 无未来数据泄漏：asof 之后行情根本不读入内存；篡改之后的数据不影响该 asof 预测。
- 每条预测可通过 `run_id` / `model_version` 追溯到当时的完整配置。
